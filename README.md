# SCP：收容失效 — Web 同人重制

基于浏览器技术（Three.js + Web Audio + Canvas）从零实现的《SCP – Containment Breach》同人致敬版。
所有贴图、音效均为程序运行时即时生成，无任何外部素材文件（唯一的静态资源是站点图标 `favicon.svg` / `favicon.ico` / `apple-touch-icon.png`，不参与游戏运行）；文本为自创概述性写作。

## 运行方式

方式零（在线直接玩）：<https://hotsteel2901.github.io/SCP_CB_Web_DS/>

方式一（推荐）：

```bash
cd 本目录
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

方式二：直接双击 `index.html`（Chrome / Edge 桌面版）。

需要键鼠，建议 Chrome/Edge 最新版。点击“开始游戏”后自动锁定鼠标。

## 玩法

你是 D-9341。SCP-173 收容间的例行清洁因全站门控失灵演变为收容失效。
穿过 轻收容区(LCZ) → 检查点A → 重收容区(HCZ) → 检查点B(特斯拉门) → 入口区(EZ)，
逐级获取 1→4 级钥匙卡（或用 SCP-914 的“精制”档升级钥匙卡），
最后在 **A 大门** 或 **B 大门** 之间选择一条撤离路线。

| 按键 | 功能 |
| --- | --- |
| W A S D | 移动 |
| Shift | 冲刺（消耗体力） |
| Space | 主动眨眼（重置眨眼条） |
| E | 互动 / 拾取 / 开关门 |
| Tab | 背包（左键使用/装备，右键丢弃） |
| F3 | 控制台（`help` 查看指令） |
| Esc | 暂停（暂停菜单内可查看成就） |

## 通关流程（与原作一致的三条主线）

1. **取得门禁**：档案室/储藏间的 1 级卡 → 测试室 2 级卡 → 服务器机房 3 级卡 → 行政区办公室 4 级卡（SCP-914 可升级）。
2. **恢复供电**：入口区**电子中心**的四个闸门全部推上，电梯与大门控制系统才会通电。
3. **选择出口**
   - **A 大门**（`gateaentrance`）：若已用**召回协议 RP-106-N** 收容 SCP-106 → 结局 A2（被基金会回收）；未收容 → 结局 A1（混沌分裂者接走你）。
   - **B 大门**（控制室电梯）：进入 75 秒撤离倒计时。
     - 阿尔法核弹头**已武装**且**远程引爆已启用** → 结局 B2（核爆，SCP-682 依然存活）。
     - 否则机动特遣队抵达 → 结局 B3（活着走出 Site-19）。
   - 也可以先与 **SCP-079** 对话，让它直接解锁 B 大门电梯。

## 收容物

### 会追你的

- **SCP-173**：被注视时无法移动；你眨眼或视线离开的每一瞬间，它都在逼近。Keter 难度下它会撞开普通门。
- **SCP-106**：随机在设施地面留下黑色泥潭，踩上去它才会爬出来穿墙追击；被抓住会坠入口袋维度——8 扇门只有 1 扇能回到设施。重收容区收容间内可执行 **RP-106-N 召回协议**：先放置“股骨破坏器”引诱，再启动召回程序。
- **SCP-096**：坐在重收容区某条走廊。看到它的脸 = 触发追杀，它会拆掉沿途所有门。别看。
- **SCP-049 与 SCP-049-2**：瘟疫医生会缓慢跟随你，被它触碰后 40 秒内会转变成 049-2（服用 SCP-500 可治愈）。医务室与 SCP-008 收容间里有游荡的 049-2 实例。
- **SCP-939**：没有眼睛，靠**声音**捕猎。走路 13 米内会被听见，**奔跑 26 米内**会被听见。安静绕开，或把生肉丢在地上引开它们。
- **SCP-966**：只有在**夜视仪**里才能看见的睡眠杀手；被注视时会僵住，你眨眼时它会扑过来。
- **SCP-1048-A**：长满耳朵的泰迪熊。听到耳朵摩擦声立刻离开——靠近 2.6 米会因尖叫瞬间死亡。
- **SCP-513-1**：摇响牛铃之后跟着你的高瘦影子。看它它会消失并出现在你背后。
- **SCP-035**：占有面具及其宿主，靠近会被攻击。

### 会害你的

- **SCP-008**（僵尸瘟疫，气体 + 感染）、**SCP-012**（未完成的乐谱，强制自残）
- **SCP-895**（监控画面，观看即死；佩戴 SCP-714 / 148 免疫）、**SCP-205**（影灯）
- **SCP-1123**（暴行头骨，触碰会被记忆冲击）、**SCP-1162**（墙中之洞：给你东西，拿走你的一部分）
- **SCP-1025**（阅读会染上书中描述的疾病）、**SCP-789-J**（马桶幽灵，无毒）

### 好东西与特殊道具

- **SCP-914**：五档旋钮（粗制 / 糙制 / 1:1 / 精制 / 极精制）。“精制”升级钥匙卡与装备，“极精制”可能给你万能钥匙卡，也可能给出一堆废料。
- **SCP-500「万灵药」**：清除感染与疾病、回满生命。
- **SCP-714「玉石戒指」**：免疫 SCP-012 / 895 等精神影响，代价是更容易犯困（眨眼更快）。
- **SCP-427「洛夫克拉夫特挂坠」**：持续再生，但佩戴超过约一分钟会突变致死。
- **SCP-148「铁灵合金」**：削弱异常伤害。
- **SCP-860「蓝钥匙」**：进入 SCP-860-1 针叶林，跑向小木屋就能活着回来（林中有 860-3）。
- **SCP-1499「GP-5 防毒面具」**：戴上后进入异界，摘下面具即可返回。
- **SCP-294**：入口区餐厅的咖啡机。**输入任何液体名称**——从 `water`、`coffee`、`life` 到 `antimatter`（后者会让你和站点一起消失）。
- **装备**：防毒面具、防化服、防弹背心、夜视仪、S-NAV / S-NAV 终极导航仪（显示地图与收容物位置）、注射器、急救包、滴眼液、收音机、电池，以及大量可阅读的档案文件。

## 提示

- 检查点大门会在数秒后自动关闭，可以用来甩开身后的东西（对 096 无效，它会拆门）。
- 特斯拉门有充能预警音，掐准节奏冲刺通过；被电到会掉 70 点生命。
- 停电时所有人都看不见——包括你，但 173 不需要看见你。
- 维护通道闸门需要密码（密码记录在 SCP-372 收容间的监控屏上）。
- 地图种子相同则布局相同，可在标题界面输入种子复盘。

## 技术说明

- `js/layout.js` 程序化生成三区网格地图（迷宫算法 + 44 个特殊房间按种子放置 + 钥匙卡进度可解性校验）
- `js/map.js` 将布局构建为合并网格的 Three.js 场景（口袋维度、B 大门平台）
- `js/rooms.js` 收录原作 `Data/rooms.ini` 中的房间：档案室、测试室、监控室、D 级居住区、
  SCP-012 / 049 / 008 / 035 / 205 / 513 / 966 / 1123 / 1162 / 500+1499 收容间、棺材室、核弹头井、
  管道走廊、维护通道、餐厅(294)、电子中心、行政区办公室、洗手间、服务器机房等
- `js/scps.js` 收容物 AI：049 / 049-2、939（听觉）、966（夜视可见）、372、1048 / 1048-A、513-1、
  035 宿主，以及房间事件（012 强制自残、205 影灯、895 监控、970 循环走廊、1123 记忆、789-J）
- `js/endgame.js` 终局系统：电子中心供电、核弹头武装 / 远程引爆、A / B 大门四条结局、
  SCP-860-1 森林与 SCP-1499 异界、机动特遣队演出、新物品使用逻辑
- `js/content.js` 84 种物品、48 份档案、SCP-914 配方表、61 种 SCP-294 饮料、39 项成就
- `js/art2.js` 512px 高清程序化环境贴图 + 新物品图标 + 重绘的 SCP-173 面部
- `js/achv.js` 成就系统（本地存档 + 提示条 + 列表）
- `js/audio.js` Web Audio 合成全部音效与环境声，广播用 SpeechSynthesis
- 无构建步骤、无网络依赖（Three.js r147 已本地化于 `lib/`）
